## 2026-08-07

- **[Creation]**: Documented the **bit-plane (bpl) multiplication variant** — the third BFP grid, [PE Grid (Bit-Plane BFP)](architectures/top_NxN_bpl_bfp.md), plus its six modules and five testbenches. The idea is one identity: for an unsigned `a`, `Σₖ aₖ·bₖ = Σₕ 2ʰ · Σⱼ (a₂ⱼ[h]·b₂ⱼ + a₂ⱼ₊₁[h]·b₂ⱼ₊₁)`, so each lane pair needs **one 4:1 multiplexer per bit plane** selecting `{0, b₂ⱼ, b₂ⱼ₊₁, b₂ⱼ + b₂ⱼ₊₁}` — no Booth recoding, no partial-product generation. The fourth input is a function of **B alone**, so it is hoisted into the per-column dispatcher and the adders are paid `N` times instead of `N²`: the same `O(N²) → O(N)` lever as the square variant's α/β generators, but bought with one widened dispatcher instead of two extra arrays.
- **[Creation]**: **Bit-plane module family** — [gate_b_n_bpl_bfp](modules/gate_b_n_bpl_bfp.md) (widen to the exact signed value at `WIDTH+1`, pairwise sums at `WIDTH+2` — two bits, because the unsigned pair reaches `2·(2^WIDTH −1)` and the signed pair `−2^WIDTH`), [disp_array_b_bpl_bfp](modules/disp_array_b_bpl_bfp.md) (that gate per DP8, placed **after** the conditioning gate so the sums are of the values the DP8 actually multiplies), [dp_8_bpl_bfp](modules/dp_8_bpl_bfp.md) (32 muxes → 8 × CPR 4:2 → 4 × CPR 4:2 → one CPR **9:2**, with a Baugh–Wooley fold for the weight-2⁷ plane: `comp_n` on the column pair plus a single `+2⁸` row, both gated by `is_signed_a`), [pe_array_bpl_bfp](modules/pe_array_bpl_bfp.md), [acc_array_bpl_bfp](modules/acc_array_bpl_bfp.md) and [pe_bpl_bfp](modules/pe_bpl_bfp.md). `is_signed_b` is consumed in the dispatcher and **never reaches the PEs**; `b_sum_dp8` becomes a third operand bus, masked by `en_i` alongside the other four.
- **[Creation]**: **Bit-plane testbenches** — [tb_disp_array_bpl_bfp](testbenches/tb_disp_array_bpl_bfp.md), [tb_dp_8_bpl_bfp](testbenches/tb_dp_8_bpl_bfp.md), [tb_pe_array_bpl_bfp](testbenches/tb_pe_array_bpl_bfp.md), [tb_acc_array_bpl_bfp](testbenches/tb_acc_array_bpl_bfp.md) and [tb_top_NxN_bpl_bfp](testbenches/tb_top_NxN_bpl_bfp.md). All pass with 0 mismatches — 11/11 modes at every level, 66/66 at the grid. Two properties are worth recording. The DP8's **sign-consistency is established by simulation, not by construction**: its tightest compressor stage sits only ~6 % inside the `2^(W−1) > Σ|rows|` bound (a resolved B element spans `[−8, 15]`, so four pair-sum rows reach 120 against 128), which is why the stimulus is corner-biased. And the tree bench compares **resolved tap values rather than bit patterns** — the bit-plane reduction reaches the same number through a different carry-save encoding, so demanding bit-identity to the Booth tree would be wrong, not merely strict.
- **[Update]**: Re-ran area, power, per-mode and intra-PE across **all five** grids and extended [Synthesis Area](experiments/syn_area.md), [Synthesis Power](experiments/syn_pwr.md), [Per-Mode Synthesis Power](experiments/syn_mode_pwr.md), [Intra-PE Area](experiments/syn_pe_area.md) and [Grid Scaling](experiments/syn_scaling.md) from four variants to five.
